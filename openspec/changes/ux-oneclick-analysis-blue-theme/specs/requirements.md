# Requirements

1. One-click analysis
   - R1: After selecting an image on Upload, user can start AI analysis in one click.
   - R2: The one-click action navigates to Analysis and starts analysis automatically.
   - R3: Analysis page must not auto-start unless explicitly requested (query flag) to avoid unexpected costs.

2. Blue theme
   - R4: Global accent changes to a vibrant blue and is applied consistently across pages.
